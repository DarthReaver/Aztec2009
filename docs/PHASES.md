# Learning Autodesk Maya 2009 Foundation: implementation phases

Goal: someone can follow the book (`reference/Learning Autodesk Maya 2009 - foundation ...pdf`, 29 lessons in 5
projects) in Aztec 2009. Each phase ends with an audit (coverage against the lessons, a scripted walkthrough
test, effect on the program, docs).

| # | Phase | Lessons | Status |
|---|---|---|---|
| 1 | Workspace and transform foundations | Intro, 1, 4, 5 | **done** (see PHASE1_AUDIT.md) |
| 2 | Dependency graph tools: Hypergraph, Connection Editor, Hypershade, Add Attribute, Channel Control, Sets | 6, 3 | done (see PHASE2_AUDIT.md) |
| 3 | Polygon modeling, complete | 2, 7 | done (see PHASE3_AUDIT.md) |
| 4 | Polygon texturing as in the book (real UVs, UV editor) | 3, 8 | done (see PHASE4_AUDIT.md) |
| 5 | NURBS part A: curves and surfaces | 1, 2, 5, 15, 16 | done (see PHASE5_AUDIT.md) |
| 6 | NURBS part B: trim, rebuild, convert, texturing | 2, 6, 15, 16 | done (see PHASE6_AUDIT.md) |
| 7 | Animation fundamentals: tangents, infinity, Dope Sheet, motion paths, sound | 4, 14, 22 | done (see PHASE7_AUDIT.md) |
| 8 | Character setup: skeleton tools, IK solvers, skin weights, lattice, characters, references | 9-13, 17 | done (see PHASE8_AUDIT.md) |
| 9 | Deformers and Paint Effects | 18, 19 | done (see PHASE9_AUDIT.md) |
| 10 | Lighting, rendering, render layers and passes | 20, 21, 28 | done (see PHASE10_AUDIT.md) |
| 11 | Dynamics: rigid bodies, particles, fields | 24, 26 | done (see PHASE11_AUDIT.md) |

| 14 | Final read-through of every lesson | all | done (see FINAL_AUDIT.md) |

Out of scope: Toxik (Lesson 29, a separate product) and mental ray (the ray tracer and software renderer
stand in for it behind the same settings windows).
